# 论文框架与实现

依据用户于2026年11月提供的《A股市场状态识别_研究论文初稿.docx》。原文是研究设计和待检验假设，无已经验证的实证结论；代码保持这一区分。附件原文不自动发布到GitHub。

## 四类候选解释

稳定Stable、趋势Trending、分化／脆弱Fragile、危机Crisis不天然互斥。模型首先输出数字簇和完整概率，不能按收益高低强行贴四个标签。

首次训练按60日收益中心排序初始化数字ID；以后在原始特征坐标中，以前窗尺度归一距离、匈牙利匹配对齐。记录alignment_cost，不把中心匹配等同经济机制永久不变。

论文版候选画像评分：稳定偏低波、高宽度、低行业分化；趋势偏高效率与方向性；脆弱偏正收益集中、低宽度、风格分化；危机偏下行波动、负收益、低宽度与共振。每簇独立匹配，允许重复；最高分不大于零或领先差不足0.25时保留unresolved。阈值是工程默认，需要预注册与稳健性检验；分数不是置信概率。核心版缺少结构因子，不赋经济标签。

## 特征

| 模块 | 指标与口径 |
|---|---|
| 趋势 | 20/60日累计对数收益；20日净位移／累计绝对价格变化 |
| 风险 | 20日年化样本波动、下行平方收益均值平方根；过去60个收盘价路径最大回撤 |
| 活跃度 | 20日／60日成交额均值比，不等于流通换手率；成交额252日经验分位 |
| 波动结构 | 20/60日波动比；(high−low)/close的20日均值 |
| 宽度 | 历史成分、当日可交易且至少60日可观察股票的20日均线上方比例；辅助上涨和新高比例 |
| 行业 | 上涨比例、等权收益离散、正负收益HHI代理、正收益Top3份额代理、成交额HHI |
| 轮动与共振 | 不重叠20日排名持续性和Top3更替率、60日行业平均相关性与第一特征值占比 |
| 风格 | 中证500／沪深300的20日累计相对对数收益 |

核心版使用10个指数指标；论文版选取附录A代表项、无正贡献标识与60日方向锚，共14个输入。其余行业指标保留在特征函数中作为候选诊断；尚未宣称完成最优去冗余、PCA或组间平衡。

### 行业贡献边界

无真实点时个股行业归属和市值权重，因此目前使用固定行业指数等权收益代理。不能解释为真实全A市值贡献。全部行业20日收益非正时，原始正贡献份额和HHI保持NaN；模型字段以零加industry_no_positive=1明确编码结构性不适用，不跨时间插值。真实历史归属、点时权重和版本衔接是后续数据扩展。

## 模型与时序

预测t的训练数据严格早于t。各训练窗独立估计分位截尾和MAD尺度；MAD近零时先回退训练标准差，再用固定单位尺度。全负行业标识不分位截尾。默认对角协方差、多个初始化、固定种子、协方差正则；GMM未收敛则报错。

首个训练窗输出K=2..6 AIC/BIC，不从测试收益反复挑K。记录训练范围、小簇权重、匹配成本与收敛。似然加尺度Jacobian，但因截尾仍只是截尾特征密度，不是未来收益预测；不能跨不同特征空间直接比较。

HMM仅在训练窗拟合，实时输出采用前向过滤；训练窗内部的后验只作训练画像，绝不作为OOS交易信号。五类规则基准用训练窗收益与效率阈值形成上涨、震荡上涨、震荡、震荡下跌、下跌，不替换四类综合机制。

## 外部结果与推断

未来5/20/60日收益、峰谷回撤、分位、正收益和尾损概率仅用于评估。硬标签和概率加权均值保留完整时间轴，使用h−1阶Bartlett HAC。报告独立状态片段，不能将连续危机日当成独立危机事件。

描述性增量回归控制趋势、波动和可用风格，加入K−1状态概率，输出HAC区间和报告内BH校正。它不是事前预测回归，也不证明因果；生成变量误差和跨模型搜索未得到完整处理。

相似案例在查询时点重新拟合同一个GMM，统一重算候选与查询概率；固定0.5的JS散度和标准化均方距离，不从未来调参。候选结果须已全部可见，相互间隔至少h日。尚未检验嵌套OOS分布预测增益。

## 策略对照

预定义行业20日Top3动量、Bottom3反转、60日协方差等风险贡献和大小盘20日相对动量。默认每21日决策，对照固定敞口、趋势规则敞口、状态条件敞口。状态条件敞口仅为训练窗60日方向为正的簇的后验之和，未为每个状态事后选择最优策略。

t收盘决策，t+1收盘执行并计成本，t+2首次产生新持仓收益；期间权重漂移，现金利息为零。使用理论指数价格和连续权重，不含ETF跟踪、分红、整手、涨跌停、停牌、冲击成本和完整税费，不能当成真实下单回测。
